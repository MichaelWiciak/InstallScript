# macScript

To update brew, run `brew update && brew upgrade && brew cleanup && brew upgrade --cask --greedy` in the terminal. This will update Homebrew, upgrade all installed packages, clean up any outdated versions, and upgrade all cask applications including those that are not marked as "auto-updated".

then run `brew bundle` to install everything in the Brewfile. This will ensure that all the necessary packages and applications are installed on your system as specified in the Brewfile.
